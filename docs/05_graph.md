🎯 Задачи:

1. Слой коммерческой недвижимости

Добавить на готовую карту Красноярска (reports/krasnoyarsk_population_map.html) новый слой со всей доступной недвижимостью.

Формат: Отобразить объекты точками.

Цветовая дифференциация (по стоимости аренды):

🟢 Зеленый — до 50к руб/мес.

🟡 Желтый — от 50к до 100к руб/мес.

🔴 Красный — дороже 100к руб/мес.

💡 Подсказка по инструментам: Используй folium.FeatureGroup() для создания отдельного слоя (чтобы его можно было включать/выключать) и folium.CircleMarker() для компактного отображения большого количества точек.

2. Универсальная отрисовка результатов

Написать функцию, которая принимает на вход путь к .geojson файлу с кандидатами и наносит их на карту.

Формат: Крупные красные маркеры со звездами.

Информативность: При клике должен открываться всплывающий Popup с бизнес-метриками (адрес, цена, площадь, потенциальный охват населения).

💡 Подсказка по инструментам: Для иконок подойдет folium.Icon(color='red', icon='star'), а красиво оформить текст внутри окна поможет folium.Popup() (туда можно передавать базовые HTML-теги вроде <b> или <br>).

3. Граф доступности (Анализ связности сети)

Написать функцию отрисовки топологического графа.

Узлы (Nodes): Текущие ПВЗ должны быть мелкими и серыми (фон), а новые кандидаты — крупными и красными (фокус).

Ребра (Edges): Соединить каждого кандидата с 3-мя ближайшими текущими ПВЗ.

💡 Подсказка по инструментам:

Математика: Для быстрого поиска 3 ближайших точек идеально подойдет алгоритм cKDTree из библиотеки scipy.spatial.

Визуал (на выбор): Ты можешь собрать статичную картинку в networkx + matplotlib (обязательно сделай линии полупрозрачными alpha=0.3, чтобы избежать визуального шума). Если захочешь сделать круто — используй библиотеку pyvis. Она принимает граф из networkx и генерирует красивый интерактивный HTML-файл с физикой отталкивания.

4. Метрика графа

Вывести обычный print() со средним расстоянием (в метрах) от новых точек-кандидатов до их соседей из старой сети. Это нужно для защиты, чтобы показать, насколько органично мы вписываемся в покрытие.
